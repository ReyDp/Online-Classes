# Online Classes Infographic

A modern, accessible, and interactive educational web infographic designed as a digital academic poster about **Online Classes**. Created for an academic English presentation, this project provides a structured, visually engaging overview of virtual learning ecosystems, highlighting definitions, key benefits, realistic challenges, and practical tips for academic success.

**Author / Presenter:** Reynaldo José Durán Pertuz  
**Course Context:** Academic English Activity (Comprehension &amp; Writing Skills)  
**Live Demo:** [https://reydp.github.io/Online-Classes/](https://reydp.github.io/Online-Classes/)

---

## Overview

Unlike conventional multi-page websites or generic blogs, this project is crafted specifically as a **vertical digital infographic poster**. It incorporates clean visual hierarchy, semantic layout blocks, self-contained SVG icons, geometric timeline connectors, and subtle micro-interactions to deliver academic content clearly and professionally.

---

## Technologies

This project adheres to modern web standards with zero external heavy frameworks:

- **HTML5**: Semantic tags (`<header>`, `<main>`, `<section>`, `<article>`, `<blockquote>`, `<footer>`), structured landmark regions, and WCAG AA accessibility compliance.
- **CSS3**: Custom design tokens, CSS Grid and Flexbox layouts, ambient radial lighting, fluid typography via `clamp()`, and `@media print` styling for PDF generation.
- **JavaScript (Vanilla)**: Lightweight progressive enhancements including an interactive reading progress bar, `IntersectionObserver` scroll reveals, accessibility keyboard support, and print triggers.

## Sections Included

The infographic consists of four mandatory content sections alongside an executive header and a final conclusion:

1. **Header & Context Badge**
   - Main Title: *ONLINE CLASSES*
   - Subtitle: *Learn anywhere, anytime.*
   - Student Attribution & Executive Matrix Ribbon.

2. **Section 1: What Are Online Classes? (Definition)**
   - Academic definition covering digital course delivery, internet access, teacher/peer interaction, and technology integration.
   - Dual visual platform badges (Laptop &amp; Global Connectivity).

3. **Section 2: Benefits (3 Key Advantages)**
   - **01. Flexibility**: Self-scheduled learning and multi-location access.
   - **02. Accessibility**: Remote coursework without constant physical campus presence.
   - **03. Self-Paced Learning**: Autonomous review and pace organization.

4. **Section 3: Challenges (3 Critical Obstacles)**
   - **01. Technical Problems**: Connectivity interruptions and hardware difficulties.
   - **02. Time Management**: Self-discipline, schedule planning, and deadline management.
   - **03. Limited Social Interaction**: Reduced face-to-face contact and virtual isolation.

5. **Section 4: Tips for Success (3 Actionable Strategies)**
   - **01. Create a Study Schedule**: Structured study windows and proactive assignment planning.
   - **02. Stay Active and Participate**: Proactive question asking, forums, and teacher-peer dialogue.
   - **03. Avoid Distractions**: Quiet designated study zones and digital noise minimization.

6. **Final Message & Attribution**
   - Highlighted closing takeaway on motivation, organization, and responsibility.
   - Formal signature block: **REYNALDO JOSÉ DURÁN PERTUZ**.

## Deployment to GitHub Pages

To publish this project to GitHub Pages, follow these simple steps:

### Step 1: Push Code to GitHub
Ensure all files (`index.html`, `style.css`, `script.js`, `README.md`) are committed and pushed to your repository branch (`main`):

```bash
git add .
git commit -m "feat: complete academic online classes infographic"
git push origin main
```

### Step 2: Configure GitHub Pages in Repository Settings
1. Navigate to your GitHub repository: `https://github.com/ReyDp/Online-Classes`
2. Click on the **Settings** tab (gear icon at the top right).
3. In the left sidebar, click on **Pages** (under the "Code and automation" section).
4. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
5. Under **Branch**, select `main` and keep the folder set to `/(root)`.
6. Click **Save**.

### Step 3: Access Live Site
After 1–2 minutes, GitHub Pages will deploy your infographic. You will receive a live URL:
`https://reydp.github.io/Online-Classes/`
